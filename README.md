# Middle Powers Hackathon

This is our workspace for the [Middle Powers: AI Safety Hackathon](https://mangrove.one/hackathon/middle-powers-hackathon). The question is how countries other than the US and China can help AI development go well.

- [ideas.md](ideas.md): the event summary, the landscape research and all ideas.
- [notes.md](notes.md): discussion notes and the current shortlist.
- **Live site: https://tubaali.github.io/middle-powers-hackathon/**
- **[Routes to AI safeguards](https://tubaali.github.io/middle-powers-hackathon/routes/#basis=model):** all 32 routes on an evidence-informed feasibility/impact model, with explicit imputations and stable overlap separation. Select a route for its reasoning and sources; switch views for matched-pool coverage calculations. [Method and checks](routes/README.md) · [Earlier eight-route estimates](routes/estimates.html).
- **[Before Geneva](https://tubaali.github.io/middle-powers-hackathon/routes/research.html):** ten scenarios, actual decision windows, required agreements and five sourced numerical examples. [Research brief](reports/Safeguard%20validation%20by%20Geneva.md) · [Source data](data/geneva-research.json).
- **[Retrieved coordinate evidence](routes/coordinate-evidence.html):** source-linked inputs and unresolved retrieval gaps for all 32 routes, cross-route datasets, downloadable input tables and receipts. No new scatter coordinates. [Research report](reports/Route%20coordinate%20evidence.md) · [Normalized data](data/coordinate-evidence.json).
- **[Stress tests](routes/stress-tests.html):** new evidence for all 32 routes, retained dissent and eight proposed follow-up tests, alongside 15 sensitivity scenarios of the unchanged original model. [Report](reports/Safeguard%20proposal%20stress%20tests.md) · [Public data](data/stress-tests.json) · [Build and local headless test commands](routes/README.md#research-stress-tests).
- **[Play Before Geneva](https://tubaali.github.io/middle-powers-hackathon/game/):** an anime diplomatic visual novel with 32 research-linked conversations, eight monthly councils, follow-up tests and consequence-driven endings. [Game guide](game/README.md) · [Original Orbit Accord prototype](game/orbit.html).
- **[Anime game stills](game/concepts/):** four Gemini-generated scenes with separate editable interface overlays, original artwork downloads and [reusable subscription-backed image tools](tools/image-generation/README.md).
- [index.html](index.html): the Leverage Map prototype. Run `python3 -m http.server` in this folder and open http://localhost:8000. Data is in [data/](data/).
- [RESEARCH-STATUS.md](RESEARCH-STATUS.md): live research allocation, source coverage and handoff status.
- [Financial leverage synthesis](reports/Financial%20leverage%20for%20safer%20AI.md): financing flows, Anthropic filing evidence and coalition decision rights (31 October 2026).
- [Finance layer handoff](reports/Finance%20layer%20handoff.md): proposed Coalition Builder fields, evidence rules and design corrections.
- [Transaction-level follow-up](reports/Finance%20decision%20rights%20followup.md): EuroHPC contract path, Anthropic new-credit limits and Cohere's unknown funding conditions.
- [Clarification questions](reports/Finance%20clarification%20questions.md): precise next evidence requests for team use; not sent.
- [Finance research records](data/finance-research/README.md): five candidate rights, nine source/access entries, explicit scope and unknowns, and a local validator.
